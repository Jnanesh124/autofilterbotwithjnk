
# Ignore Words Management

This directory contains the ignore words system for the auto-filter bot.

## Commands:
- `/addword <word>` - Add a word to ignore list
- `/removeword <word>` - Remove a word from ignore list  
- `/listwords` - List all ignore words

## Default Ignore Words:
- in, upload, series, full, horror, thriller, mystery, print, file

## How it Works:
When users search for movies, these words are automatically filtered out from the search query to provide better results.

## Admin Only:
Only bot admins can manage ignore words for security reasons.
